# Archived blog posts

`posts/` preserves the previously generated HTML for Afternoon, Summerstorm,
and 2023, along with their old listing and feed. The original Markdown files
are no longer present in `content/posts/`.

This directory is outside Hugo's content and static directories, so these
files are not included in the published site. Do not copy them into `public/`
unless you intend to publish them again.
